ECOSYSTEM MATRIX // オートウルゴス

THE AUTOURGOS FRAMEWORK

A modular, zero-dependency Python ecosystem: one decoupled package per capability. Works with any OpenAI-compatible LLM.

Pure Python. Zero External Dependencies.

Unlike bloated agent SDKs that lock you into single cloud providers or hide the reasoning loop, Autourgos isolates each capability into lightweight, composable packages. Bring any model: OpenAI, Groq, Mistral, Together, DeepSeek, or local Ollama/vLLM instances.

PYPI RELEASE v3.11.0 ↗ AGENT REPOSITORY ↗
# Quickstart: 3-line autonomous agent
from autourgos_agent import Agent
from autourgos_core import Toolbox

agent = Agent(
  llm="openai/gpt-4o",
  tools=Toolbox.load("system_tools")
)
result = agent.run("Execute autonomous workflow")
print(result.final_answer)
