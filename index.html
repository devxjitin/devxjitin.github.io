02 // flagship

  
Autourgos

  

    
A modular agent framework where every piece — LLM client, memory, skills, human interrupts, computer-use tools, speech — is its own small package. Bring any OpenAI-compatible LLM; no lock-in.

    

      
    
        
  • Thought → Action → Observation loop with native tool-calling mode
    • 
        
  • Async everywhere, parallel tool calls
    • 
        
  • 11 lifecycle hooks and approval gates for human-in-the-loop
    • 
        
  • Works with OpenAI, Groq, Mistral, DeepSeek, Ollama, vLLM and more
